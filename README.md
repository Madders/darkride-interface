<h1 align="center">Darkride</h1>

<p align="center">A social virtual world for VR and desktop.</p>

<p align="center"><a href="https://vr.darkride.ai">vr.darkride.ai</a> · <a href="https://vr.darkride.ai/discord">Discord</a></p>

This repository holds Darkride's client and its world servers. Darkride isn't open to the public yet: follow along on [Discord](https://vr.darkride.ai/discord).

## Downloads and building

- **Windows:** installers and zips are on the [Releases](https://github.com/Madders/darkride-interface/releases) page. To build it yourself, see [BUILD_WINDOWS.md](BUILD_WINDOWS.md).
- **A world server on Linux:** a Docker image, `docker pull ghcr.io/madders/darkride-server:latest`; to run it or build it, see [docker/README.md](docker/README.md).
- **Everything else:** [BUILD.md](BUILD.md) lists each platform's guide and how well it's tested.

## Made with AI

Darkride makes extensive use of artificial intelligence in its development: much of its code is written with AI coding assistants. If AI-assisted development ("vibe coding") isn't your thing, no hard feelings. This may not be the project you're looking for.
